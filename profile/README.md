<h2 align="center">Concordance Developers</h2>

Организация под проект Dead Space 14 — самостоятельный сервер на [Space Station 14](https://spacestation14.com/), воссоздающий вселенную оригинальной трилогии Dead Space.

За основу взяты наработки [DS13-2.0](https://github.com/DS13-2-0/DS13-2.0) под SS13.

Денег нет. Проект держится на волонтёрах — если заинтересован, буду рад новым лицам — [Discord](https://discord.gg/YPMgZKWmaA).
